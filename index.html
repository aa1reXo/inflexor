Framing

Two tools. Two different levels of autonomy — on purpose.

"We are rebuilding the fund as an AI-first operation. Rather than adding headcount for every process, we build agents and internal software to run it. This is not a side experiment — it is how the fund operates."

— from the JD you posted

Your own thesis piece Prompting the Future: Generative AI draws a sharp line between AI Copilots (human-in-the-loop, approval gates on the decision) and AI Agents (autonomous, act without a prompt each time). I built one of each on a small orchestration layer, deliberately — no one handed me a spec for this either, per your own JD, so I made the call myself: earn trust with a copilot before you ship an agent.

◆ Copilot

Deal Triage Copilot

Ingests a deal — deck, data room, or public record — turns it into validated, structured data, and scores it against Inflexor's own public Team / TAM / Technology + S.E.T. framework, with a human-in-the-loop approval gate before anything moves forward. It never decides. It prepares.

● Agent

Portfolio Pulse

Runs on a schedule against every portfolio company, watches for signal deltas, grounds every claim in a source before writing it down, and drafts an LP-ready update — no prompt required.

Under the hood

How I'd actually build this

This is the same core architecture I shipped in production at Qualcomm — RAG + MCP tool-calling agents with stateful memory, running on GCP/Vertex AI for 200+ daily users across 55+ teams. Same pattern, different data sources: swap Jira / Axiom / Orbit for deal flow, portfolio metrics, and LP reporting.

01 · Ingest
Decks, data rooms, portfolio co. updates, public filings
→
02 · Extract
LLM + schema validation (FastAPI service, structured output)
→
03 · Ground & Verify
Cross-check every claim against a source — evals before it ships
→
04 · Orchestrate
MCP tool-calling agent on a durable orchestration layer (LangGraph), human-in-the-loop approval gates where it matters
→
05 · Deliver
Dashboard · Slack · draft LP memo

At Qualcomm this evals step is what took hallucination to near-zero on the reporting platform I built — it's the difference between a fun demo and something a partner will actually trust for diligence.
